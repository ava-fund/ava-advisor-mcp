# Security policy

## Reporting a vulnerability
Please report security issues privately to **contact@ava.fund** with the subject "Security". Don't open a public issue.
Include what you found, where (URL, repository, file), and steps to reproduce. We'll acknowledge your report and keep you
updated while we fix it.

## Secrets
Our repositories never contain API keys, tokens or credentials. If you find one in any `ava-fund` repository, please report
it as above so we can revoke it.
